# Technology Stack: Muse Spark Vibe Coding

## Core Environment & Runtimes
- **Host OS:** Windows 11 / Windows 10
- **Virtualization / Subsystem:** WSL2 (Ubuntu / Debian LTS)
- **Shells:** PowerShell 5.1/7+ (Windows Host) & Bash (WSL2 Guest)
- **Runtimes:**
  - Node.js (v20+ LTS)
  - Python 3.11+
  - Git 2.40+

## AI Agent & Model Stack
- **Primary Reasoning Model:** Muse Spark (1.1, 1.2, 1.3)
- **Agent CLI:** Meta Muse Code CLI (`muse`)
- **SDKs & Libraries:** `@muse-code/sdk` / Meta Model API Client

## Tooling & Automation
- **Automation Scripts:** PowerShell (`.ps1`) wrappers & Bash (`.sh`) setup scripts
- **Test & Validation Frameworks:** Pester (PowerShell testing) & Pytest / Bash sanity test scripts
- **IDE / Editor Integration:** Visual Studio Code / Cursor com extensão WSL Remote
